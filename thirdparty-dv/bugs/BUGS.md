**Injected fault:** `axil_crossbar_addr.v` — `m_select_next = i;` →
`m_select_next = i ^ 1;`, i.e. every decoded transaction is steered to the
wrong slave port (the direct analogue of the SDRAM project's "wrong bank
decode" bug).

**Caught by:** the reference-model scoreboard — writes land in the wrong
slave's backing memory, so both the read-back-through-the-crossbar check and
the per-slave `check_backing()` (routing + isolation) assertion fire:

```
directed_routing: slave 0 backing memory mismatch at offset 0x0000: got b1 exp b0 (routing/isolation bug?)
```

The mutation is applied only to the gitignored `work/` clone and reverted
with `git checkout`; **upstream verilog-axi is never modified**.
